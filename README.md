# Data Scientist Portfolio - Gabriele Vertullo

## Projects

### [Recipe Site Traffic Analysis](./Recipe_Site_Traffic_Analysis)

Analysis and prediction of recipe website traffic based on nutritional information, category, and servings using machine learning.

* Validated and cleaned recipe data, handling missing values and standardizing categories
* Conducted exploratory data analysis (EDA) to understand feature distributions and relationships
* Developed and evaluated Logistic Regression and Random Forest classification models
* Tuned the Logistic Regression model threshold to achieve the business goal of >= 80% recall for high-traffic recipes while maximizing precision

**Tools Used:** Python (Pandas, Matplotlib, Seaborn, Scikit-learn)
